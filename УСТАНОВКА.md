# Инструкция по установке и запуску системы ООО КЦД

> Не пугайся — здесь нет ничего сложного. Просто читай по шагам и делай всё по порядку.

---

## Что тебе понадобится

Всего одна программа — **Docker Desktop**. Она сама установит всё остальное внутри себя: и базу данных, и сервер, и сайт. Тебе больше ничего скачивать не нужно.

---

## Шаг 1 — Установка Docker Desktop

### На Windows:

1. Открой браузер и перейди на сайт: **https://www.docker.com/products/docker-desktop/**
2. Нажми большую кнопку **"Download for Windows"**
3. Скачается файл `Docker Desktop Installer.exe` — открой его двойным кликом
4. В установщике просто нажимай **"OK"** и **"Next"** — всё оставляй по умолчанию
5. После установки компьютер попросит **перезагрузиться** — перезагрузи
6. После перезагрузки Docker Desktop запустится сам (появится значок кита 🐳 в трее — это панель задач внизу справа)

### На Mac:

1. Открой браузер и перейди на сайт: **https://www.docker.com/products/docker-desktop/**
2. Нажми **"Download for Mac"** (выбери Apple Silicon если у тебя новый Mac с чипом M1/M2/M3, или Intel если старый)
3. Скачается файл `.dmg` — открой его, перетащи Docker в папку Applications
4. Открой Docker из папки Applications
5. Значок кита 🐳 появится в верхней панели меню

---

## Шаг 2 — Проверка что Docker установился правильно

После установки нужно убедиться, что всё работает.

**Открой терминал:**
- На Windows: нажми `Win + R`, введи `cmd`, нажми Enter (или найди "Командная строка" в меню Пуск)
- На Mac: нажми `Cmd + Пробел`, введи `Terminal`, нажми Enter

**Введи команду и нажми Enter:**
```
docker --version
```

Ты должен увидеть что-то вроде:
```
Docker version 27.0.3, build 7d4bcd8
```
Главное — чтобы не было слова "ошибка" или "error". Если видишь номер версии — всё отлично!

**Теперь проверь Docker Compose:**
```
docker compose version
```

Ты должен увидеть:
```
Docker Compose version v2.28.1
```

Если обе команды показали версии — Docker установлен правильно. Идём дальше!

> ⚠️ Если видишь ошибку — убедись, что Docker Desktop запущен (иконка кита должна быть в трее/меню). Просто открой Docker Desktop и подожди пока он загрузится (это занимает 30-60 секунд).

## Шаг 3 — Получение файлов проекта

Тебе должны были передать папку **OOO_KCD**. Внутри неё должны быть:

```
OOO_KCD/
├── backend/
├── frontend/
├── docker-compose.yml
└── .env.example
```

Положи эту папку куда тебе удобно, например:
- Windows: `C:\Projects\OOO_KCD`
- Mac: `/Users/твоё_имя/Projects/OOO_KCD`

> ⚠️ Важно: путь к папке **не должен содержать кириллицу и пробелы**. Например, папка `C:\Мои документы\ООО КЦД` — плохо. Папка `C:\Projects\OOO_KCD` — хорошо.

---

## Шаг 4 — Настройка конфигурации

В папке проекта есть файл `.env.example` — это шаблон с настройками. Нам нужно сделать из него рабочий файл.

### На Windows:

1. Открой папку `OOO_KCD` в Проводнике
2. Убедись, что видишь расширения файлов (если не видишь `.example` — в Проводнике включи "Расширения имён файлов" во вкладке "Вид")
3. Нажми на `.env.example` правой кнопкой мыши → **Копировать**
4. Нажми правой кнопкой на пустое место → **Вставить**
5. Переименуй скопированный файл: убери слово `.example`, оставь только `.env`
   - Должно получиться просто `.env`

### На Mac:

1. Открой Терминал
2. Перейди в папку проекта командой (замени путь на свой):
   ```
   cd /Users/твоё_имя/Projects/OOO_KCD
   ```
3. Скопируй файл командой:
   ```
   cp .env.example .env
   ```

### Через терминал (работает и на Windows, и на Mac):

Открой терминал, перейди в папку проекта и выполни:

**Windows (cmd):**
```
cd C:\Projects\OOO_KCD
copy .env.example .env
```

**Mac/Linux:**
```
cd ~/Projects/OOO_KCD
cp .env.example .env
```

### Что изменить в файле .env (необязательно для первого запуска):

Открой файл `.env` любым текстовым редактором (Блокнот, TextEdit, VS Code) и найди строку:
```
SECRET_KEY=change-me-to-a-long-random-secret-key-in-production
```
Замени значение на любой длинный набор случайных букв и цифр, например:
```
SECRET_KEY=aBcD1234xYzQ9876mNpR5678sTuV0123
```
Это нужно для безопасности — чтобы никто не мог подделать логины.

> Для первого тестового запуска можно не менять — система заработает и со стандартным ключом.

## Шаг 5 — Запуск системы

Открой терминал и перейди в папку проекта:

**Windows:**
```
cd C:\Projects\OOO_KCD
```

**Mac:**
```
cd ~/Projects/OOO_KCD
```

Теперь запусти одну команду:
```
docker compose up --build
```

**Что произойдёт дальше — это нормально:**

Терминал начнёт выводить много текста. Docker скачает нужные компоненты (только при первом запуске — это может занять 5-15 минут в зависимости от скорости интернета) и запустит систему.

Когда увидишь в терминале такие строки — система готова:
```
kcd_backend   | Seed: данные успешно созданы.
kcd_backend   | INFO:     Application startup complete.
kcd_frontend  | start worker process
```

> ⚠️ Не закрывай это окно терминала! Пока оно открыто — система работает. Можно свернуть.

## Шаг 6 — Открываем систему в браузере

Открой любой браузер (Chrome, Firefox, Edge) и введи в адресную строку:

```
http://localhost
```

Должна открыться страница входа в систему. 🎉

## Как остановить систему

Когда закончил работу — вернись в терминал и нажми `Ctrl + C`. Система остановится.

Чтобы запустить снова (уже без долгого скачивания):
```
docker compose up
```
(без `--build` — будет быстрее)

## Частые проблемы и решения

### ❌ "docker: command not found" или "docker не является внутренней командой"

Docker Desktop не запущен. Открой Docker Desktop и подожди, пока иконка кита перестанет крутиться (30-60 секунд). Потом попробуй снова.

---

### ❌ "port is already allocated" или "адрес уже используется"

Порт 80 занят другой программой (например, другим веб-сервером). Попробуй остановить другие запущенные docker-контейнеры:
```
docker compose down
docker compose up --build
```
Если не помогло — перезагрузи компьютер.

---

### ❌ Страница не открывается в браузере

Убедись что:
1. В терминале видна строка `Application startup complete`
2. Ты вводишь именно `http://localhost` (не https, не localhost:3000)
3. Docker Desktop показывает контейнеры как "Running" (зелёный цвет)

---

### ❌ Система запустилась, но вход не работает

Подожди 10-15 секунд и попробуй снова — база данных иногда чуть дольше запускается.

---

### ❌ Нужно начать с чистого листа (удалить все данные и начать заново)

```
docker compose down -v
docker compose up --build
```
Команда `-v` удаляет базу данных. После этого система стартует как новая.
